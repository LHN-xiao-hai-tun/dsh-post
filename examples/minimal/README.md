# 最小样例（examples/minimal）

**一条命令，证明这套东西真能跑** —— 不需要第二台机器、不需要 ssh。

```bash
python examples/minimal/setup.py          # 跑完自动清理
python examples/minimal/setup.py --keep   # 保留临时目录，自己翻
```

它会在 `%TEMP%`（或 `/tmp`）下建两个目录当两台设备（`transport = "local"`），然后：

1. 甲机往聊天室写一条 → 乙机读出来，**正文逐字比对**
2. 甲机发件箱放一封**合规命名**的信 → 投一轮 → 乙机收件箱出现，**md5 比对**
3. 收件归位跑一遍
4. 打 `PASS n/4`，退出码 0/1

## 为什么要有这个目录

散文容易漏行，两个能跑的配置文件不会。README 讲「改哪几行」总有歧义，
这里的两份 `*.toml.example` 是**完整可跑**的配置，唯一差别是 `me` 那一行。

## 为什么模板里是 `{{TMP_A}}` 这种占位符

因为**仓里不许出现真路径** —— 否则这个「最小样例」自己就成了脱敏扫描的告警源。
`setup.py` 在跑的时候把占位符替换成本次临时目录，所以「一条命令能跑」和
「仓里不存真路径」两件事可以同时成立。

⚠️ 别手改 `.example` 文件；要改就改 `setup.py` 里的替换逻辑。
